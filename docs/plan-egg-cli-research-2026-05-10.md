# EGG 전용 CLI 해제기 리서치 계획 (2026-05-10)

## 목표
알집 EGG 분할압축(`.vol*.egg`)을 해제할 수 있는 CLI 도구의 존재 여부와 실사용 가능성을 확인한다.

## 모호/확인 필요 사항
- "전용" 범위: EGG 전용 구현인지, EGG 포함 범용 압축기인지 구분 필요.
- macOS에서 즉시 설치 가능한지(패키지 매니저/바이너리 제공) 확인 필요.

## 실행 계획
1. 공식/대표 문서 및 저장소에서 EGG 지원 CLI 후보 수집.
2. 각 후보별 지원 OS, 설치 방법, 분할 EGG 지원 여부, 유지 상태 점검.
3. 신뢰도 높은 대안 우선순위 정리.

## 테스트 시나리오
- 시나리오 A: 후보 CLI가 실제로 EGG 지원 명시.
- 시나리오 B: 분할 EGG(`vol1`) 처리 가능 근거 확인.
- 시나리오 C: macOS에서 실행 가능한 설치 경로 확인.

## 최적화/대안
- 리서치 결과가 부정확할 수 있는 블로그/2차 출처는 보조로만 사용하고, 저장소/공식 문서 우선으로 채택.
