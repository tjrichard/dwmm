## Official Supabase MCP Evidence
- Official docs identify the hosted MCP endpoint as `https://mcp.supabase.com/mcp`.
- Official docs show remote MCP configuration with an HTTP MCP server named `supabase`.
- Official docs recommend reading security best practices before connecting an LLM to Supabase projects.
- Official docs support scoping the MCP server to a project and using read-only mode, but the exact hosted URL options are generated by Supabase's UI.

## Security Notes
- Prefer a remote hosted MCP connection with OAuth/authentication instead of committing personal access tokens or service role keys.
- Do not put service-role keys in Codex MCP config.
- Start with a read-only/project-scoped Supabase MCP session when possible.
- This repo currently has sensitive-looking Supabase keys in `.env` and `.env.local`; this request does not require changing or exposing them.

## Open Constraints
- MCP tools added to local config usually require a new Codex session/reload before they appear as callable tools in the assistant tool list.
- Network is restricted for shell commands in this environment, so package-download based MCP servers would require escalation. The hosted remote HTTP MCP avoids npm installation.
